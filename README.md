# 🐴 Rig Clone — Security Verification for AI Coding Agents

A full-fidelity, pixel-perfect clone of **[Rig](https://rig.ai/)** (as featured on [Minimal Gallery](https://minimal.gallery)).

Live GitHub Pages mirror:  
👉 **[https://classyvaibhav06.github.io/rig-clone/](https://classyvaibhav06.github.io/rig-clone/)**

---

## 🛠️ Overview
- **Source Website:** [https://rig.ai/](https://rig.ai/)
- **Tech Stack:** Astro, Tailwind CSS, WebGPU/Three.js shaders, custom typography (`GeistPixel`, `ChivoMono`, `InstrumentSans`, `Chalet London`).
- **Features Preserved:**
  - Complete responsive layout, typography, and vectors.
  - Interactive radar loops, security scanning animations, and agent verification timeline.
  - Full asset bundle with `.nojekyll` configuration for zero-error GitHub Pages hosting.
